# 统计协调工具能力清单

- 日期：2026-11-08
- 工具名：`admissions_statistics`
- 目标：理解自然语言中的指标、筛选条件和分组维度，协调计划、录取、报到、成绩和志愿数据完成统计
- 边界：只执行白名单聚合查询，不生成 SQL 文本，不返回学生个人明细

## 一、已实现指标

### 计划与录取

| 指标 | 口径 |
|---|---|
| 计划数 | `fact.plan.plan_count` 求和 |
| 录取数 | `fact.admission_record` 计数 |
| 计划完成率 | 录取数 ÷ 计划数 × 100% |
| 调剂数 | `fact.admission_summary.adjusted_count` 求和 |
| 调剂率 | 调剂数 ÷ 录取数 × 100% |

### 报到

| 指标 | 口径 |
|---|---|
| 报到数 | `admission_record.is_enrolled=1` 的记录数 |
| 报到率 | 报到数 ÷ 录取数 × 100% |

### 成绩与位次

| 指标 | 口径 |
|---|---|
| 最高分 | 投档分最大值 |
| 最低分 | 投档分最小值 |
| 平均分 | 投档分平均值 |
| 中位分 | 投档分中位数 |
| 下四分位分 | 投档分 25% 分位 |
| 最高分位次 | `rank_no` 最小值 |
| 最低分位次 | `rank_no` 最大值 |
| 平均分位次 | `rank_no` 平均值 |
| 广东投档排位 | 广东省考生的 `rank_no` 最小、最大和平均值 |

### 志愿与报考

| 指标 | 口径 |
|---|---|
| 志愿数 | `fact.major_choice` 志愿记录数 |
| 志愿率 | 志愿数 ÷ 计划数 × 100% |
| 报考数 | 选择该专业的不同考生数 |
| 报考率 | 报考数 ÷ 计划数 × 100% |
| 一志愿录取数 | `admission_record.volunteer_order=1` |
| 一志愿录取率 | 一志愿录取数 ÷ 录取数 × 100% |
| 一志愿报考数 | `major_choice.choice_order=1` 的不同考生数 |
| 一志愿报考率 | 一志愿报考数 ÷ 计划数 × 100% |
| 2—20 志愿录取数 | `volunteer_order` 位于指定区间的记录数 |
| 2—20 志愿报考数 | `choice_order` 位于指定区间的不同考生数 |

## 二、已实现维度

- 年份
- 省份
- 科类
- 批次
- 专业
- 学院
- 层次（本科 / 专升本）
- 招生类型
- 性别
- 生源高中

学院维度已对当前 82 个专业完成映射。

## 三、暂不支持

以下字段或维度没有进入当前数据库，系统会明确提示数据不足，不会强行计算：

- 征集数
- 专业异动数
- 转出专业数
- 转入专业数
- 计划编制数
- 计划调整数
- 省控线
- 最高分线差、最低分线差、平均分线差
- 位次占比（缺少一分一段最大位次和省控线位次）
- 考生类别
- 毕业类别
- 外语语种
- 政治面貌
- 年龄
- 投档单位代码、投档单位名称
- 原始专业代码
- 校区
- 地市、区县
- 选科要求
- 国际专业代码、校编代码

## 四、自然语言示例

```text
2026年各专业一志愿录取率和调剂率
2025年各学院报到率和计划完成率
2026年各专业最高分、最低分、平均分和中位分
2026年各专业2到20志愿报考情况
2026年广东投档排位情况
2026年各专业性别情况
```

## 五、当前限制

1. 一次查询只支持一个主分组维度，暂不支持“学院 + 专业”这种双重交叉表。
2. 志愿率、报考率以计划数为分母，是产品分析口径，不等同于省考试院官方口径。
3. 中位分和下四分位分基于当前录取记录的投档分。
4. 招生类型分组使用录取类型字段，个别来源数据的计划类型与录取类型可能不完全一致。
5. 不支持字段不会估算或编造。
