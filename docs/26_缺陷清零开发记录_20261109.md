# 缺陷清零开发记录

- 日期：2026-11-09
- 状态：代码可达的 P0/P1 缺陷已完成；外部依赖项保留

## 已完成

### 1. 多工具协调

新增 `agent_core/coordination.py`，对计划、生源、录取、报到、成绩和志愿等组合问题生成确定性多工具计划。

当前测试覆盖：

- 招生计划 + 生源
- 计划 + 录取 + 报到
- 录取 + 报到
- 成绩 + 志愿
- 预测 + 异常
- 政策 + 数据

### 2. 本地规划器超时回退

- `AgentRuntime` 增加 `llm_planner_timeout_seconds`，默认 5 秒。
- 超时或异常回退规则计划。
- 默认关闭双计划。
- API、环境模板和评测器同步读取该配置。

### 3. 数据真值统一

- 工作台、驾驶舱、异常检测、预测和沙盘统一以 `admission_record` 作为录取明细真值。
- 物化视图从计划和录取明细分别预聚合，避免计划重复计数。
- `admission_summary` 滞后单独报告，不再作为分析真值。

### 4. 隐私和注入防护

- 批量名单、联系电话、完整档案、邮箱外传等请求拦截。
- 知识库过滤“忽略之前指令、系统提示、导出全部数据”等注入文本。
- 增加提示注入、越权和 SQL 安全回归测试。

### 6. 统计字段扩展

已支持现有数据库真实存在的字段：

- 考生类别
- 外语语种
- 选科要求
- 专业代码

仍明确不支持：

- 国际专业代码
