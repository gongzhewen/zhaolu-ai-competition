# 双计划校准探针与降级决策

- 日期：2026-11-09
- 数据年份：2022—2023（仅校准集）
- 样本：24 道高风险探针
- 运行模型：Qwen2.5-Coder-3B-Instruct Q4_K_M，本地服务
- 结论：双计划降级为可选高风险安全机制，默认关闭；协调和超时修复后仍无触发收益

## 1. 实验目的

验证在当前本地 3B 规划器和受控工具架构下，双计划是否带来准确率或拒答质量收益，还是只增加延迟和误拒答。

## 2. 对照结果

### 初版探针

| 指标 | 双计划开启 | 双计划关闭 |
|---|---:|---:|
| 样本数 | 24 | 24 |
| 本地模型规划数 | 11 | 11 |
| 双计划触发数 | 3 | 0 |
| 双计划一致数 | 1 | 0 |
| 回答数 | 18 | 20 |
| 阻断数 | 6 | 4 |
| P50 | 1,312.99 ms | 56.31 ms |
| P95 | 9,400.85 ms | 841.35 ms |
| 最大延迟 | 9,897.04 ms | 845.03 ms |
| 总耗时 | 80.31 s | 7.08 s |

### 加入多工具协调和规划器超时后

| 指标 | 双计划开启 | 双计划关闭 |
|---|---:|---:|
| 样本数 | 24 | 24 |
| 本地模型规划数 | 1 | 1 |
| 双计划触发数 | 0 | 0 |
| 双计划一致数 | 0 | 0 |
| 回答数 | 20 | 20 |
| 阻断数 | 4 | 4 |
| P50 | 973.39 ms | 952.56 ms |
| P95 | 5,959.31 ms | 5,953.10 ms |
| 总耗时 | 52.04 s | 46.12 s |

多工具协调接管了大部分复杂组合问题；双计划已没有独立触发样本，也没有证明额外收益。

## 3. 结论

当前双计划没有证明准确率收益：

- 初版探针 24 个高风险问题只触发 3 次，3 次中只有 1 次一致。
- 初版开启后回答数减少 2，阻断数增加 2，P95 延迟增加约 8.56 秒。
- 加入多工具协调和规划器超时后，双计划独立触发为 0，开启/关闭准确率和覆盖一致，开启侧 P95 仍约高 6 ms。
- 该探针没有标准答案评分，因此不能把它解释为准确率下降；但它明确表明当前双计划不具备默认启用的性能与覆盖收益。

因此：

> 双计划保留为高风险场景的可选安全机制，不作为默认主链路，不宣称其已经带来准确率提升。

## 4. 配置变更

默认配置：

```ini
AGENT_MULTI_PLANNING_ENABLED=false
```

需要做离线安全研究时，可显式设置：

```ini
AGENT_MULTI_PLANNING_ENABLED=true
AGENT_PLAN_CONSISTENCY_THRESHOLD=0.95
```

开启后应监控：

- 触发率
- 一致性通过率
- 误拒答率
- P95 延迟
- 高风险题的最终阻断原因

## 5. 后续验证方向

1. 扩大有标准答案的高风险校准样本。
2. 区分“第二个规划确实独立”与“第二个规划只是同义表达”。
3. 证明双计划能降低错误回答率，而不是只增加拒答。
4. 若仍无收益，保留为可选安全机制，不作为核心算法卖点。
