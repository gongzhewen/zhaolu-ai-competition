## 4. 模型灰度、故障回退与回滚

新增能力：

- `MINIMIND_MODEL_VERSIONS`：版本到端点、模型名的映射。
- `MINIMIND_STABLE_VERSION`：稳定版本 ID。
- `MINIMIND_CANARY_VERSION`：灰度版本 ID。
- `MINIMIND_CANARY_PERCENT`：0—100 的确定性流量比例。
- 灰度端点失败自动回退稳定端点。
- 版本级成功、超时、错误和拒绝指标。

真实 3B 模型演练：

```text
灰度 100%：选择 canary
灰度端点故障：自动回退 stable，并记录 fallback_from=canary
回滚：canary 比例设为 0，选择 stable
```

## 5. 部署方式

默认单实例配置不变：

```bash
docker compose -f docker-compose.baota.yml --env-file .env.baota up -d
```

双实例 + Redis：

```bash
docker compose \
  -p zhaolu-ai-v2 \
  --env-file .env.docker \
  -f docker-compose.yml \
  -f docker-compose.cluster.yml \
  up -d
```

该组合包含：

- MySQL
- Redis 7
- backend（127.0.0.1:8000）
- backend-2（127.0.0.1:8001）
- web/Nginx

多学校独立数据面示例：

```ini
SCHOOL_DATABASE_URLS={"1":"mysql+asyncmy://school1_user:password@db1:3306/zhaolu_v2","2":"mysql+asyncmy://school2_user:password@db2:3306/zhaolu_v2"}
```

映射存在时，任何未配置的 `school_id` 都会被拒绝，而不是回落默认库。
