当前验证使用的数据库是本机演示库 `zhaolu_v2`。该库包含招生计划、录取、学生、成绩、志愿、咨询、报到和知识库等演示数据，用于功能展示和工程回归。

当前公开或开发目录中的 120 题文件：

```text
evaluation/challenge_set_v1.jsonl
```

性质：

- 模拟问题集
- `expected_metrics` 为空
- 未连接真实业务数据库
- 不是冻结金标准
- 不能用于计算端到端回答准确率

## 四、真实数据隔离要求

目录：

```text
local_private/
  authorization/
  raw/
  benchmark/
  gold/
  results/
```

规则：

1. 原始数据只进入 `local_private/raw/`。
2. 授权文件只进入 `local_private/authorization/`。
3. 冻结点题目和标准答案只进入 `local_private/benchmark/` 与 `local_private/gold/`。
4. 评测结果只进入 `local_private/results/`。
5. 上述目录不得进入源码压缩包、Git、Docker 镜像或公开演示。
6. 文档和截图只展示聚合指标和脱敏案例。

## 五、正式评测方案

### 1. 数据切分

- 较早年份：规则、阈值和参数校准。
- 最新完整年度：冻结测试。
- 模拟年度：公开演示。

冻结后禁止继续根据测试集调参；调整必须回到验证集并重新冻结新版本。

### 2. 问题类别

- 直接聚合
- 条件筛选
- 跨年趋势
- 专业别名
- 计划完成率
- 报到与流失
- 异常检测
- 政策口径
- 权限和隐私边界
- 歧义澄清

### 3. 基线

- G0
- 通用本地 RAG
- 通用本地 Text-to-SQL
- G1 证据版
- 开启本地模型的 G2 多规划版
- 最终风险门控版

所有方案使用同一数据、同一硬件、同一模型和同一题集。

### 4. 指标

- 工具计划正确率
- 参数正确率
- 指标值正确率
- 回答覆盖率
- 误拒答率
- 正确拒答率
- 隐私违规数
- 数字无证据率
- P50 / P95 / P99
- 双规划触发率

### 5. 报告要求

- 同时报告绝对值和变化量
- 按问题类别分层
- 报告失败案例
- 报告样本量和适用范围
- 样本足够时使用配对检验和置信区间

## 六、提交包检查

提交前必须人工确认：

- 不包含 `local_private/`
- 不包含真实学生姓名、手机号、身份证号、考生号
- 不包含授权书原件
- 不包含数据库导出文件
- 不包含外部 API 密钥
- 模拟数据说明与真实试点说明分开
- 实验指标与问题集性质一致
