# 风险阈值校准与冻结决策

- 日期：2026-11-09
- 校准集：2022—2023，120 题
- 冻结测试集：2024—2025，120 题
- 结论：保留当前 `AGENT_RISK_THRESHOLD=0.32`

## 1. 校准结果

使用真实校准集独立生成风险分数后，校准曲线选择最低成本阈值：

```text
selected_threshold = 0.07315
answer_sample_count = 96
block_sample_count = 24
false_answer_rate = 16.67%
false_refusal_rate = 0%
answer_coverage = 83.33%
```

当前阈值 `0.32` 的校准结果：

```text
false_answer_rate = 41.67%
false_refusal_rate = 0%
answer_coverage = 88.33%
```

校准集本身偏向更低阈值，因为它更积极地拦截边界题。

## 2. 冻结测试集一次性验证

在最终测试集上只做一次配置验证：

| 阈值 | 总体准确率 | 应答题准确率 | 正确拒答率 | 回答覆盖率 |
|---|---:|---:|---:|---:|
| 0.32（保留） | 100% | 100% | 100% | 80.00% |
| 0.07315（未采用） | 99.17% | 100% | 95.83% | 80.83% |

低阈值没有带来测试集整体收益，反而使正确拒答率下降。因此不能仅凭校准集的表面收益切换阈值。

## 3. 决策

保留：

```ini
AGENT_RISK_THRESHOLD=0.32
```

`0.07315` 记录为一次候选校准结果，不删除，但未冻结为生产配置。

## 4. 解释边界

- 这次测试验证属于事后冻结测试集的一次性检查，不是前瞻盲测。
- 阈值选择只使用 2022—2023 校准集。
- 2024—2025 的验证结果不能用于继续搜索更好阈值；否则会重新污染测试集。
- 未来若更换风险特征、模型或数据版本，应升级测试集版本（如 v3）后再校准。
