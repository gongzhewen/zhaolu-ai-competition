# 前端第一驱动力 UI 重构

- 日期：2026-11-10
- 设计原则：以招生人员的决策效率为第一驱动力
- 功能边界：不新增、不删除、不改变任何业务功能和接口

## 1. 设计方向

原界面以通用后台管理结构为主，功能完整，但页面层级更接近“信息展示系统”。本次重构将界面定位为“招生办公操作台”，围绕以下工作链路组织布局：

```text
判断现状 → 定位风险 → 追问原因 → 形成行动
```

主要设计原则：

- 使用纯色和细边框，不使用渐变、发光、装饰圆形和网格背景。
- 使用白底侧边栏、浅灰工作区和单一蓝色主色。
- 删除“智”字图标、英文眉题、卡片编号和无业务含义的小字。
- 页面标题与年度、筛选等操作条件放在同一紧凑页头。
- 指标卡降低高度，只保留业务名称和数值。
- 表格、筛选器和常用操作优先进入首屏，图表作为辅助信息后置。
- 信息、警告和错误提示改为无边框行内说明，不再使用整块提示卡片。

## 2. 共享结构

新增共享页面开场组件：

```text
apps/web/src/components/layout/page-hero.tsx
```

新增独立设计覆盖层：

```text
apps/web/src/ui-refresh.css
```

覆盖层在原有全局样式和移动端兼容样式之后加载，保留既有页面样式能力，同时统一新的视觉语言。

共享壳层变化：

- 侧边栏改为 232px 白底导航，减少层级背景和菜单间距。
- 品牌区只保留“招录智策”文字，不保留附加图标。
- 顶栏压缩为 52px，只保留当前页面、用户和退出操作。
- 主内容改为纯浅灰背景，移除所有装饰性背景和进入动画。
- 登录页改回单卡片、单任务结构，去掉品牌展板和说明性小字。
- 模板下载、口径待核验、模拟数据等提示保留图标和文字层级，但去掉底色、边框、圆角和整块留白。

## 3. 页面改造

已接入统一页面开场区的主要页面：

- 招生工作台
- 招生驾驶舱
- 生源分析
- 预测与预警
- AI 异常检测
- AI 招录助手
- AI 数据洞察
- 报告中心
- 数据导入
- DBF 原始数据导入
- 数据质量
- 计划策略沙盘
- 用户管理
- 角色权限
- 审计日志

重点布局调整：

- 招生工作台增加独立“常用操作”侧栏，计划填报、数据导入、AI 问数和异常查看可直接进入。
- 学生信息管理将年度切换合并进页头，学生筛选和名册移动到首屏主路径。
- 学生管理进度和年度规模图表下移到名册之后，避免次要信息阻断查询操作。
- 招生计划、专业名称修正的原有大幅介绍区压缩为普通操作页头。

## 4. 功能不变约束

本次重构没有修改：

- 任何 API 路径、请求参数或返回结构。
- 登录、查询、导入、编辑、删除、导出和 AI 对话逻辑。
- 页面路由和菜单权限。
- 数据口径、统计规则和模型调用链路。
- 移动端业务操作能力。

改动集中在：

- JSX 页面结构与视觉分组。
- 共享页面开场组件。
- CSS 设计 token、布局、颜色、阴影、间距和响应式规则。
- Ant Design 主题 token。
