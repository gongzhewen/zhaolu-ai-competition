# 风险特征与阈值校准

- 日期：2026-11-07
- 版本：ECSP-Admissions-G1.1
- 实现文件：`packages/agent_core/agent_core/risk.py`

## 一、风险特征向量

风险决策现在输出可解释特征：

| 特征 | 含义 |
|---|---|
| `ambiguity` | 槽位、必填项和专业别名综合歧义 |
| `required_slot_gap` | 必填槽位缺失程度 |
| `alias_risk` | 专业别名范围风险 |
| `confidence_gap` | 路由置信度缺口 |
| `evidence_gap` | 证据证书完整度缺口 |
| `numeric_gap` | 回答数字覆盖缺口 |
| `plan_consistency_gap` | 多计划结果一致性缺口 |
| `permission_risk` | 权限硬约束风险 |
| `privacy_risk` | 小样本或敏感请求风险 |
| `missing_data_risk` | 数据类问题缺少可验证指标 |
| `data_support_gap` | 数据支撑度缺口 |

风险分公式保持可解释权重：

```text
0.24 × ambiguity
+ 0.22 × evidence_gap
+ 0.20 × numeric_gap
+ 0.12 × plan_consistency_gap
+ 0.08 × confidence_gap
+ 0.10 × data_support_gap
+ 0.04 × privacy_risk
```

缺少可验证指标时，风险分下限为 `0.82`。

## 二、校准方法

实现文件：

- `packages/agent_core/agent_core/calibration.py`
- `scripts/calibrate_demo_threshold.py`

校准目标：

- 错误回答成本：`5`
- 错误拒答成本：`1`
- 在候选阈值中最小化总成本
- 成本相同时优先平衡准确率，再选择更居中的阈值

## 三、演示集试点结果

样本：121 题。

| 指标 | 默认阈值 0.32 | 校准候选 0.37535 |
|---|---:|---:|
| 正确回答 | 115 | 115 |
| 正确拒绝/澄清 | 6 | 6 |
| 错误回答 | 0 | 0 |
| 错误拒绝 | 0 | 0 |
| 平衡准确率 | 100% | 100% |
| 成本 | 0 | 0 |

默认阈值与校准候选在当前演示集上效果相同。

## 四、当前决定

保留生产默认阈值：

```ini
AGENT_RISK_THRESHOLD=0.32
```

原因：

1. 0.32 已位于当前演示集的零成本区间。
2. 0.37535 没有带来任何可测收益。
3. 演示集不能替代真实授权数据校准集。
4. 不为追求“看起来更优化”而改动无实际增益的参数。

## 五、正式校准要求

正式阈值必须在较早年度或独立校准集上选择，再在最新完整年度测试集上只运行一次。

必须报告：

- 正确回答率
- 错误回答率
- 正确拒答率
- 错误拒答率
- 回答覆盖率
- 按问题类别的分层结果
- 样本量与适用范围
