## 2. 为什么废弃 v1

v1 登记为 `m1-real-frozen-v1`，不再作为 M1 的权威评测集，原因如下：

1. v1 冻结后发现测试集混入 6 道 2024 年单条件题，2024 又属于校准年份。
2. v1 的跨年趋势测试题使用 2024 作为对照年，仍然依赖校准年份答案。
3. v1 有两道题与校准集完全相同。
4. v1 生成后本地数据库已重置；其标准答案中的学生数、计划数等与当前数据库不一致。
5. v1 的“快照 ID”只包含统计计数和日期，无法充分区分内容变化。

v1 文件保留用于审计追踪，但任何 M2 评测必须只读取 v2。

## 5. 标准答案方法

标准答案直接由确定性 SQL 查询基础事实表和维度表生成，不调用智能体，不使用智能体输出，也不使用 `analytics.mv_admissions_rollup`。

主要口径：

- 计划数：`fact.plan.plan_count` 求和。
- 录取数：`fact.admission_record` 行数。
- 报到数：`fact.admission_record.is_enrolled=1`。
- 计划完成率：录取数 / 计划数 × 100%。
- 报到率：报到数 / 录取数 × 100%。
- 成绩指标：直接聚合 `fact.admission_record.score`。
- 志愿与报考：直接聚合 `fact.major_choice`。
- 专业别名：直接读取 `dim.major_alias` 与 `dim.major` 映射。
- 分数段：按 `FLOOR(score/10)*10` 划分。
- 官方统计：直接聚合 `fact.authoritative_admission_stat`。

独立复核脚本使用另一套查询路径，对 192 道应答题逐题重新计算数值，并逐项比较允许误差；48 道边界题同时检查预期策略及无数据条件。

- 校准集应答题只引用 2022 或 2023。
- 专业别名池跨切分交集为 0。
- 测试集未用于阈值、规则、提示词或别名校准。

必须披露：

- 2024、2025 数据在开发过程中已被观察。
- v2 是事后冻结，不是从未观察过的前瞻测试集。
- v2 通过并不等同于“真实业务准确率已证明”；M2 仍需冻结算法配置后只运行一次最终测试。

```powershell

$env:REDIS_ENABLED='false'
```
