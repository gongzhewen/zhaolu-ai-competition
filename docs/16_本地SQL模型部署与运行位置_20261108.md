## 七、资源提醒

3B Q4 模型运行时工作集约 3.57GB。加上 MySQL、Backend 和 Nginx 后，不适合完整 2 核 4G 一体化部署。

适用方式：

- 演示/评测电脑单独运行模型服务。
- 2 核 4G 服务器只运行业务系统，不建议同时加载 3B 模型。
- 如必须在 4GB 内运行模型，使用 1.5B 轻量版本并重新实测。
