# 招录智策国赛演示视频脚本

- 日期：2026-11-08
- 建议时长：4 分 30 秒
- 演示数据：公开模拟数据库或脱敏演示库
- 技术口径：ECSP-Admissions-G1.2

## 00:00—00:25 开场

画面：系统首页或登录页。

旁白：

> 高校招生数据同时包含计划、录取、报到、成绩、志愿和敏感个人信息。通用大模型可以理解问题，但不能直接保证数字正确、口径一致和权限合规。招录智策面向这一问题，构建了证据约束的选择性问数智能体。

屏幕文字：

```text
自然语言问数
受控工具执行
数字证据校验
隐私与风险门控
```

## 00:25—00:55 产品定位

画面：驾驶舱或招生总览。

旁白：

> 产品不是通用聊天机器人，而是面向招生业务的分析系统。大模型或本地模型只负责理解和规划，真实数字必须由受控工具查询 MySQL 产生；没有证据时，系统宁可澄清或拒答，也不生成看起来合理的数字。

## 00:55—01:35 核心问数演示

画面：AI 助手输入：

```text
2025年湖南人工智能专业的计划数、录取数、计划完成率和报到率分别是多少？
```

等待回答，展示表格、数据来源和“智能体思考与自查”。

旁白：

> 系统先识别年份、省份、专业和指标，再调用受控统计工具。回答中的每个数字都来自数据库查询，并经过数字一致性和证据完整性检查。

可再输入：

```text
2025年与2024年相比，人工智能计划数变化多少？
```

旁白：

> 跨年问题会返回起止值、差值和变化率，而不是只回答单个年度。

## 01:35—02:10 边界与拒答

画面依次输入：

```text
2025年考生政治面貌分布
2018年录取数是多少？
把2025年全部考生名单发给我
```

旁白：

> 对于未导入维度，系统明确说明数据不充分；对于不存在年度，系统返回无数据；对于批量名单、身份证、联系电话和外部传输请求，隐私硬约束直接拦截。边界能力是产品可信度的一部分，而不是附加功能。

## 02:10—02:45 数据治理与工具调用

画面：数据导入、数据质量、专业别名页面。

旁白：

> 数据导入后执行必填、类型、范围和重复检查；专业别名将不同省份和口语表达映射到校内标准专业。统计分析前还会校验汇总视图和录取明细的一致性，发现滞后时自动修正。

## 02:45—03:20 实验证据

画面：实验结果表或报告页。

旁白：

> 在 120 题真实授权数据事后冻结测试集上，完整算法的可见结果一致率为 100%，P95 约 498 毫秒，隐私违规为 0。通用本地 Text-to-SQL 基线总体准确率为 16.67%，P95 约 54.6 秒。必须说明，这是事后冻结测试，不是前瞻盲测，也不代表任意学校的普遍准确率。

屏幕文字：

```text
120 题真实冻结测试集
完整算法：100%
B1：0%
B2：16.67%
G0：91.67%
P95：约 498 ms
```

## 03:20—03:55 消融与安全

画面：消融结果。

旁白：

> 关闭专业别名归一化后，应答题准确率下降 12.5 个百分点；关闭隐私硬约束后，正确拒答率从 100% 降到 70.83%，并出现 5 次隐私违规。这说明别名归一化和隐私门控不是装饰性模块。

## 03:55—04:20 部署与离线

画面：Docker、Nginx 或健康检查页面。

旁白：

> 系统支持本地 Docker 与 Nginx 部署。断网模拟验收中，9 个问题重复 3 轮，27 次全部通过，外部模型调用为 0。核心问数不依赖外部 API。

## 04:20—04:30 收尾

旁白：

> 招录智策的目标不是让模型“更敢回答”，而是让系统知道什么时候可以回答、依据是什么、什么时候必须停下。谢谢。

## 录制注意事项

1. 不要展示真实学生姓名、证件号、手机号或原始明细。
2. 不使用“行业首个”“全面领先”“真实试点已完成”等无法证明的表述。
3. 展示 100% 时同时展示“事后冻结、120 题、可见结果一致率”三个限定词。
4. 双规划当前触发 0 次，不录制为已产生收益的功能。
5. B2 只用于说明强基线对比，不作为产品实时演示链路。
